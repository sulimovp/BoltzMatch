# Review: BoltzMatch

## 1. What the project is and where it stands

This repository (`sulimovp/BoltzMatch`, forked from `kfattila/BoltzMatch`) is not an active draft manuscript; it is the archived 2019–2020 codebase of an already-published paper (Sulimov, Voronkova, and Kertész-Farkas, *Bioinformatics* 36(12):3781–3787, June 2020, [doi:10.1093/bioinformatics/btaa206](https://doi.org/10.1093/bioinformatics/btaa206)), reopened in October–November 2026 to decide whether the line of work can be revived. The published claim is that a Restricted Boltzmann Machine with a dense bilinear weight matrix $W \in \mathbb{R}^{d \times d}$ (unit diagonal; ~4M parameters at 1.0005 Da bin width, ~1.6B at 0.05 Da), trained per LC-MS/MS run via a weakly supervised softmax loss over confident Tailor-calibrated PSMs (`q < 0.005`) plus a "diversifying" regularizer, learns chemically explainable peak-pair relationships and improves database-search sensitivity (+33% low-res, +50% high-res vs. Tide XCorr at 0.1% FDR) when the transformed spectra are exported to `.ms2` and searched with a modified Crux/Tide binary.

There is no manuscript, no target venue, no submission deadline, no roadmap/TODO file, and no result table inside the repository. The fork adds only [AGENTS.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/AGENTS.md), a 2026-10-11 internal code review ([docs/REVIEW.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/REVIEW.md)), a 10-check bug-confirmation script ([tests/verify_bugs.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/tests/verify_bugs.py) and [docs/verify_output.txt](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/verify_output.txt)), and a 2026-11-05 halt notice at the bottom of [README.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/README.md#L88-L90) requiring an independent novelty review before any further work. Git history ([.git/logs/HEAD](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/.git/logs/HEAD)) confirms no fix branches have been committed yet. *(Note on inspection scope: sandbox permissions denied shell directory listing of `C:\Users\suli\Downloads\Papers\BoltzMatch`, so all files referenced across the repo, source modules, tests, and benchmark scripts were read directly without unpacking the Git LFS `.zip` archives in `ms_data/` and `fasta/`.)*

All quantitative evidence currently available comes exclusively from the 2020 paper (summarized in [docs/REVIEW.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/REVIEW.md#L183-L193)); the repository cannot execute on a current Python/PyTorch/NumPy/pandas/Biopython stack, omits the HeLa dataset used in the paper's Prosit comparison, and has never been audited with entrapment FDR. Meanwhile, the original HSE group already superseded BoltzMatch's dense matrix with **Slider** (*J. Proteome Res.* 2021, 465–4,105 convolutional parameters) and built exact high-res calibration (**HR-XPV**, *Proteomics* 2024) and large-scale search (**Tide v4.3**, *J. Proteome Res.* 2025). What remains completely open is whether any revived BoltzMatch/Slider variant has a publishable research claim in 2026, whether its FDR control survives entrapment testing, and whether per-run spectral adaptation adds anything beyond modern deep rescoring and foundation models.

## 2. Independent assessment

Judged against the 2024–2026 state of the art, BoltzMatch's original claim—a standalone, per-run learned bilinear scoring matrix for DDA database search—is obsolete for any competitive bioinformatics or proteomics venue (*Bioinformatics*, *J. Proteome Res.*, *Molecular & Cellular Proteomics*, *Nature Methods*, *ISMB*). Even in 2020, BoltzMatch lost to 2019 Andromeda + Prosit + Percolator at 1% FDR on HeLa (2,071 vs. 2,176 PSMs; [docs/REVIEW.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/REVIEW.md#L189)). Between 2024 and 2026, four shifts have left the original framing behind:

1. **Prediction-based rescoring harmonizes first-pass engines.** Modern pipelines (**MS²Rescore 3.0**, **Oktoberfest**, **MSBooster**) inject predicted fragment intensities, retention times, and ion mobility into Percolator/mokapot, boosting identifications by +30–89% and collapsing variance across seven database search engines from ~67% down to ~8–10% (Winkelhardt et al., 2026). Improving a single first-pass dot product in isolation now delivers sharply diminishing returns.
2. **Chimeric spectrum deconvolution breaks the 1-PSM-per-spectrum ceiling.** **CHIMERYS** (*Nat. Methods* 2025) and **MSFragger-DDA+** (*Nat. Commun.* 2025) identify multiple co-fragmented peptides per MS2 scan (~2× identifications), which a single-winner bilinear matcher cannot match.
3. **End-to-end neural matchers and MS/MS foundation models supersede per-run bilinear matrices.** Models pretrained on $10^7$–$10^9$ spectra (**SpecEncoder**, **DDA-BERT**, **pUniFind**, **Tesorai Search**, **yHydra**, **InstaNovo-FM**) learn nonlinear, sequence- and chemistry-aware spectrum/peptide representations that handle open search, rare PTMs, and even label-free peak-physics pretraining.
4. **Entrapment FDR auditing is now expected for learned scorers.** **FDRBench** (Wen et al., *Nat. Methods* 2025) and recent non-linear rescoring audits (Nameni et al., bioRxiv 2026) show that high-capacity models trained with target-decoy supervision can silently inflate true entrapment FDR by >5× while passing standard decoy checks. BoltzMatch's in-sample target-biased training, decoy-driven epoch selection, and worst-third AUC check would trigger immediate rejection.

## 3. Problems and bugs

The audit below includes **critical bugs and baseline flaws newly found by reading the code and scripts that [docs/REVIEW.md](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/REVIEW.md) missed**, factual errors inside `docs/REVIEW.md` itself, and verified bugs from the repository.

### 3.1 Exported `.ms2` spectra silently discard `rbm_hb` (new — missed by `docs/REVIEW.md`)
- **Severity:** Blocker
- **Evidence:** [source/utils.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/utils.py#L124-L135) (`transofrm_spectra`), [source/dbsearch.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/dbsearch.py#L685-L700) (`export_spectra_ms2`), [rbm_train_main.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/rbm_train_main.py#L179-L180), [source/models.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/models.py#L63-L69), [docs/verify_output.txt](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/verify_output.txt#L9).
- **Why it matters:** During training and diversifying regularization (`utils.py:383`), the hidden score is $s W + b_h$, and `rbm_hb` receives the largest gradient norm in the model (`|grad hb| = 1.73` vs. `|grad W| = 1.64` in `verify_output.txt:9`). During Python epoch selection (`transofrm_spectra`), `s @ W` is stored in `spectrum.spectrum_array` while `rbm_hb` is stored separately in `peptide.bias`. However, `export_spectra_ms2` writes **only** `spectrum.spectrum_array`. Because $s W h + b_h^\top h = (s W + b_h^\top) h$, Crux/Tide never sees `rbm_hb` at all: the paper's final numbers evaluate a co-adapted `W` with its learned bias vector stripped away.
- **How to fix:** Either fold `rbm_hb` directly into the exported transformed spectrum (`transformed = visible_data @ rbm_weights + rbm_hb`, removing `peptide.bias` from `boltzmatch_tailor_scoring`), or drop `rbm_hb` from training and regularization so the learned operator is purely linear ($s \mapsto s W$).
- **Certainty:** High (100% verified directly from source).

### 3.2 In-sample target-biased training and decoy-guided epoch selection invalidate FDR control
- **Severity:** Blocker
- **Evidence:** [rbm_train_main.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/rbm_train_main.py#L112-L186) (specifically epoch selection on `np.sum(PSMs)` at L176), [source/utils.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/utils.py#L52-L90).
- **Why it matters:** A 4M-parameter (low-res) or 1.6B-parameter (high-res) matrix $W$ plus `rbm_hb` and the best epoch are all fitted on the exact same spectrum set on which TDC FDR is reported, using confident target PSMs (`q < 0.005`) as positives. Even though Crux evaluates against protein-reversed decoys unseen during training, a dense $d \times d$ matrix can memorize bin co-occurrences of true target peptides and inflate scores for homologous or false target sequences relative to decoys—precisely the mechanism shown by Nameni et al. (2026) to push entrapment FDR from 1% to ~6.3%. Checking target-vs-decoy AUC (0.51) on the worst-scoring third of PSMs tests the uninformative bottom tail, not the 0.1%–1% decision boundary.
- **How to fix:** Train with peptide-disjoint $K$-fold cross-validation across spectra (following mokapot) or train on one run and evaluate strictly on held-out runs; select epochs by held-out NLL without using decoys; verify FDR calibration using `FDRBench` entrapment (Wen et al., 2025).
- **Certainty:** High (100%).

### 3.3 Diversifying regularizer (`div_reg`) is dominated by all-zero skipped rows and suffers sign cancellation via `abs(mean(...))` (new — missed by `docs/REVIEW.md`)
- **Severity:** Blocker
- **Evidence:** [rbm_train_main.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/rbm_train_main.py#L123-L141), [source/utils.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/utils.py#L47-L57), [source/utils.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/utils.py#L366-L387).
- **Why it matters:** `prepare_batch_data` allocates a zero matrix of shape `(batch_size, dim)` and leaves every skipped spectrum (`qvalue >= 0.005`, typically 70–95% of an MS2 run) as an all-zero row. `calculate_div_reg` then computes `hidden_representation = visible_data @ W + rbm_hb` on **all** `batch_size` rows and takes all $\binom{128}{2} = 8{,}128$ pairs via `choose_indices(batch_size)`. Every skipped row evaluates to `rbm_hb`, so ~64–90% of pairs are `(zero, zero)` pairs contributing `rbm_hb**2` (an accidental penalty on `rbm_hb` with zero gradient on `W`), and most remaining pairs are `(active, zero)`. Worse, `abs(div_reg_rate * torch.mean(h1 * h2))` averages across all pairs and all $d$ bins *before* taking `abs`, so positive and negative products cancel globally rather than enforcing pairwise orthogonality, and the gradient flips sign discontinuously at 0. In addition, fixing the dropped-tail batch bug (`M6`) causes `choose_indices(batch_size)` to raise `IndexError` on the last partial batch.
- **How to fix:** Slice `experimental_spectra` to active (non-skipped) rows only before computing `div_reg`; compute pairwise diversity using the actual active count (via $O(B d)$ identity on L2-normalized rows); replace `abs(mean(h1 * h2))` with a non-canceling squared off-diagonal penalty such as $\frac{1}{B(B-1)} \sum_{p \neq q} (\hat{h}_p^\top \hat{h}_q)^2$.
- **Certainty:** High (100% verified from source).

### 3.4 `int16` overflow silently corrupts all high-resolution theoretical peaks above m/z ~1638 Da
- **Severity:** Blocker
- **Evidence:** [source/utils.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/utils.py#L183-L188), confirmed in [tests/verify_bugs.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/tests/verify_bugs.py#L27-L38) and [docs/verify_output.txt](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/docs/verify_output.txt#L2-L6).
- **Why it matters:** `generate_unique_theoretical_peaks` casts fragment bin indices to `np.int16` (max 32,767). At `bin_width=0.05` Da (`max_bin=40000`), every theoretical fragment above m/z ~1638 wraps to a negative integer (`-32768` to `-25537`), which NumPy and PyTorch silently index from the end of the array (mapping them to unrelated m/z ~361–723 Da bins). Every high-resolution model reported in the 2020 paper (`humvar`, `iprg`, `malaria`) was trained on corrupted theoretical spectra.
- **How to fix:** Replace `dtype=np.int16` with `dtype=np.int32` at lines 183–187.
- **Certainty:** High (100%, test-confirmed).

## 4. New ideas and extensions of existing ideas

### 4.1 Sharper claim: Entrapment-safe, zero-library test-time spectral adaptation with exact p-values on OOD chemistries
- **What to do:** Drop the 2020 claim of beating standard HCD tryptic search engines with a dense $W$. Build a compact, shift-invariant + low-rank linear spectral operator $T_\theta(s) = (I + C_\theta) s + U V^\top s$ (Slider-style Toeplitz mass-offset convolution $C_\theta$ capturing isotopes, neutral losses, and flanking/complementary offsets, optionally conditioned on coarse amino-acid/PTM flags), paired with **HR-XPV** exact p-values (Bhimani et al., 2024) on top of **Tide v4.3**. Target specifically **out-of-distribution acquisition and chemistry regimes** where pretrained predictors (Prosit, MS²PIP, yHydra) fail, refuse input, or suffer heavy domain shift: UVPD, EThcD, EAD, negative-mode fragmentation, cross-linked peptides, unusual synthetic/chemical PTMs, and low-res ion-trap runs.
- **Why it raises value:** Directly answers Winkelhardt et al. (2026) by targeting regimes where prediction-based rescoring is unavailable or miscalibrated, while retaining something black-box neural matchers (`yHydra`, `Tesorai`, `pUniFind`) cannot deliver: **mathematically calibrated exact p-values** via dynamic programming on the transformed spectrum.
- **Cost:** ~40–60 hours engineering + ~20–40 GPU-hours on the ZHAW Slurm cluster using public PRIDE/MassIVE datasets (EThcD, UVPD, phosphoproteomics/exotic PTMs, immunopeptidomics).
- **Closest existing work:** Slider ([PMID 34449232](https://pubmed.ncbi.nlm.nih.gov/34449232/)), HR-XPV ([doi:10.1002/pmic.202300145](https://doi.org/10.1002/pmic.202300145)), MS²Rescore 3.0 ([doi:10.1016/j.mcpro.2024.100718](https://doi.org/10.1016/j.mcpro.2024.100718)), pUniFind ([doi:10.48550/arXiv.2507.00087](https://doi.org/10.48550/arXiv.2507.00087)).

### 4.2 Missing killer experiment: Capacity-vs-entrapment-FDR audit of learned spectral transforms
- **What to do:** Run a controlled `FDRBench` entrapment benchmark comparing (i) fixed dense BoltzMatch $W$ (4M–1.6B params), (ii) Toeplitz/convolutional $C_\theta$ (~500–4,000 params), (iii) Toeplitz + rank-$r$ $W$, (iv) same-run training vs. peptide-disjoint $K$-fold CV vs. cross-run transfer, and (v) mokapot LSVM vs. XGBoost on MS²Rescore features. Plot empirical entrapment FDR against nominal TDC $q$-value at 0.1%, 1%, and 5% FDR.
- **Why it raises value:** Turns BoltzMatch's largest liability (unverified FDR) into a timely, high-impact methodological finding. Nobody has yet mapped the entrapment-FDR phase transition across *spectral-operator capacity* (dense vs. Toeplitz) in the way Nameni et al. (2026) mapped classifier complexity in mokapot. Even if dense BoltzMatch fails entrapment while Toeplitz/cross-run passes, that contrast is directly publishable.
- **Cost:** ~25–35 hours implementation + ~15–30 GPU-hours using Tide 4.3, `FDRBench`, and 3–5 public datasets (HeLa, HumVar, Yeast, plus an entrapment-augmented database).
- **Closest existing work:** Wen et al. (*Nat. Methods* 2025, [doi:10.1038/s41592-025-02719-x](https://doi.org/10.1038/s41592-025-02719-x)), Nameni et al. (*bioRxiv* 2026, [doi:10.64898/2026.07.10.737772](https://doi.org/10.64898/2026.07.10.737772)).

### 4.3 Theoretical explanation: Exact conditions for target-decoy exchangeability under linear spectral transformations
- **What to do:** Derive formal conditions under which a learned linear spectral map $s \mapsto T_\theta(s)$ preserves TDC null exchangeability and HR-XPV calibration: (i) prove how an unconstrained $d \times d$ matrix $W$ fitted on in-sample targets can encode target-proteome fragment-mass marginals and break symmetry between false targets and decoys (even when decoys enter the softmax denominator); (ii) bound the generalization gap / null bias of a **translation-invariant Toeplitz operator** $T_\theta(s) = K_\theta * s$ whose parameter count depends only on the mass-offset window $w$ (not on $d$ or proteome size $N_{\text{pep}}$) under peptide-disjoint cross-fitting; and (iii) formalize the discretization error bound when feeding $T_\theta(s)$ into HR-XPV's dynamic-programming exact p-value calculation.
- **Why it raises value:** Gives the BoltzMatch $\to$ Slider $\to$ HR-XPV lineage a principled statistical-learning theory that differentiates it from ad-hoc deep rescoring heuristics.
- **Cost:** ~20–30 hours analytical work + <5 CPU-hours synthetic validation.
- **Closest existing work:** Kertész-Farkas, Keich & Noble (*JPR* 2015), Wen et al. (*Nat. Methods* 2025).

### 4.4 Wider setting: Residual calibration of predicted spectra and iterative chimeric deconvolution
- **What to do:** Replace the binary theoretical spectrum $h \in \{0,1\}^d$ in $\langle T_\theta(s), h \rangle$ with predicted intensities $\hat{h}_{\text{pred}}$ from Prosit/MS²PIP/AlphaPeptDeep so $T_\theta$ learns **instrument- and run-specific residual calibration** (collision-energy drift, neutral-loss ratios, background suppression) on top of sequence-specific predictions. Separately, exploit the linearity and speed of $T_\theta(s)$ to test **greedy/L1 chimeric deconvolution** (iteratively subtracting $c_1 \hat{h}_1$ from $T_\theta(s)$ and re-scoring the residual inside Tide 4.3) as an open, library-free counterpart to CHIMERYS/MSFragger-DDA+.
- **Why it raises value:** Directly addresses the two mechanisms—predicted intensities and chimeric deconvolution—responsible for most post-2020 DDA sensitivity gains.
- **Cost:** ~60–80 hours engineering + ~30–50 GPU-hours on standard and wide-window chimeric HeLa benchmarks.
- **Closest existing work:** CHIMERYS ([doi:10.1038/s41592-025-02663-w](https://doi.org/10.1038/s41592-025-02663-w)), MSFragger-DDA+ ([doi:10.1038/s41467-025-58728-z](https://doi.org/10.1038/s41467-025-58728-z)), MS²Rescore 3.0 ([doi:10.1016/j.mcpro.2024.100718](https://doi.org/10.1016/j.mcpro.2024.100718)).

### 4.5 Quantum angle (only where it fits naturally — do not force a QBM onto 40,000 bins)
- **Where a quantum angle does NOT fit:** BoltzMatch is an "RBM" in name only: training never samples a partition function over $\{0,1\}^d$ because the negative phase sums deterministically over a small finite list of candidate peptides in the precursor window ([source/models.py](file:///C:/Users/suli/Downloads/Papers/BoltzMatch/source/models.py#L57-L71)). Putting a Quantum Boltzmann Machine on 2,000–40,000 m/z bins is hardware-infeasible and attacks a non-existent computational bottleneck.
- **Where a quantum angle DOES fit naturally (separate QML/optimization track):**
  1. **Chimeric spectrum deconvolution as small-scale QUBO/Ising subset selection:** Given $M \in [16, 64]$ pre-filtered candidate peptides in an MS2 isolation window (after fast Tide/BoltzMatch scoring), selecting the sparse co-fragmenting subset $z \in \{0,1\}^M$ minimizing $\|T_\theta(s) - \sum_{m=1}^M \alpha_m z_m h_m\|_2^2 + \lambda \sum_m z_m$ is natively a quadratic binary optimization problem with coupling matrix $J_{mm'} = \alpha_m \alpha_{m'} h_m^\top h_{m'}$ capturing shared fragment-ion interference. Because $M \le 64$ per spectrum, it maps directly onto QAOA, variational quantum eigensolvers, or quantum/simulated annealers, and allows exact apples-to-apples benchmarking against classical branch-and-bound (Gurobi/MILP) and greedy OMP.
  2. **Semi-Quantum RBM over compressed fragmentation-event indicators (lower priority):** Modeling the joint distribution of $n \le 16\text{–}24$ binary fragmentation channels per cleavage site ($b, y, a, -\text{H}_2\text{O}, -\text{NH}_3, +1$ isotope, $+2$ charge, immonium ions) using a semi-quantum RBM (commuting visible, non-commuting hidden Hamiltonian) benchmarked strictly against exact classical RBMs.
- **Why it raises value:** Produces a physically grounded, honestly sized QML/combinatorial-optimization benchmark using real scientific data rather than toy synthetic QUBOs, without overclaiming proteomics SOTA.
- **Cost:** ~40–60 hours to formulate the chimeric QUBO dataset from a public wide-window DDA run and benchmark classical exact MILP/OMP vs. QAOA/annealing (<10 GPU-hours).
- **Closest existing work:** Semi-Quantum RBMs ([arXiv:2502.17562](https://doi.org/10.48550/arXiv.2502.17562), 2025), Wilde Evolved QBMs ([arXiv:2512.02721](https://doi.org/10.48550/arXiv.2512.02721), 2025), Schuman et al. Parallel Annealing QBM ([arXiv:2507.14116](https://doi.org/10.48550/arXiv.2507.14116), 2025), CHIMERYS ([doi:10.1038/s41592-025-02663-w](https://doi.org/10.1038/s41592-025-02663-w)).
